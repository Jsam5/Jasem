# مولّد ATO — JASEM

صفحة متصفح مجانية لتوليد أمر المهام الجوية (Air Tasking Order) بصيغة USMTF.

## الاستخدام

1. افتح `index.html` في المتصفح، أو شغّل خادماً محلياً من هذا المجلد.
2. عبّئ الخانات (أو استخدم «تعبئة توقيت اليوم»).
3. اضغط **Generate ATO**.
4. انسخ الأمر أو اطبعه.

لا يحتاج Excel ولا اشتراكاً — كل شيء يعمل محلياً في المتصفح.

## تشغيل محلي

```bash
cd ato
python3 -m http.server 8080 --bind 127.0.0.1
```

ثم افتح: http://127.0.0.1:8080/
