# UAE Military Wisdom Posters — Print Ready

A3 print files at **300 DPI**, military style, wisdom phrases (no “AI Revolution” text).

## How to print

1. Prefer the **PDF** files (easiest for print shops / school printers).
2. Print at **100% / Actual size** — do not “fit to page”.
3. Paper: A3 matte or satin photo paper works best for wall display.
4. Orientation:
   - Four portraits → A3 **portrait**
   - Banner → A3 **landscape**
