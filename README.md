# Jasem

أدوات عملية للزمرة السادسة وJASEM.

| المسار | الغرض |
|--------|--------|
| [`ato/`](ato/) | مولّد أمر المهام الجوية (ATO) في المتصفح — تعبئة خانات → Generate ATO → نسخ أو طباعة |
| [`print/`](print/) | ملفات طباعة الهيكل التنظيمي على فلين أبيض (A3) |
| [`scripts/`](scripts/) | سكربت توليد PDF الهيكل التنظيمي |

## مولّد ATO

```bash
cd ato
python3 -m http.server 8080 --bind 127.0.0.1
```

افتح http://127.0.0.1:8080/ — بدون Excel أو اشتراكات.
